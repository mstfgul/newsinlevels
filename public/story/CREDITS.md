# Image credits

All images below are in the public domain. Verified via the Metropolitan
Museum of Art's Open Access API (`isPublicDomain: true`) and the Wikimedia
Commons `extmetadata` API (`LicenseShortName: Public domain` / `CC0`) before
downloading. Re-encoded to WebP (quality 80–85, 800px on the long edge) with
ImageMagick — no other edits. High-resolution museum scans were fetched via
Wikimedia's own pre-resized thumbnail API (`iiurlwidth`) rather than the raw
original, to avoid unreliable multi-hundred-megabyte downloads.
